# 設置可能箇所

コースごとに、ブロックを置いてよいマスを登録する。本番・練習中は、そのマス以外にブロックを置けない。

## 登録（コース編集）

- 編集画面の「設置可能箇所」をクリックすると、マーカー（黄緑の羊毛、64個）を受け取る。Adventureでも使える。
- マーカーを置くと、そのマスが**最後に編集画面を開いたコース**の設置可能箇所になる。ブロックは置かれない（空気のまま）。
- 登録済みのマスにもう一度置くと解除。ボタンのShift＋右クリックで全削除。
- コース範囲の外、または編集画面を開いていない状態では拒否する。
- 登録・解除はアクションバーに `設置可能箇所を追加：x, y, z（N マス）` と出す。
- 設置可能箇所の変更はコースの版番号 `rev` を上げる。
- 範囲の外に設置可能箇所が残っている場合は「未設定の項目」として遊べなくする（範囲を変えたときのため）。

## 遊ぶとき

- 登録が1つもないコースは、今までどおりどこにでも置ける。
- 登録があるコースでは、それ以外の場所への設置を取り消し、その挑戦を失敗にする（本番はスタート、練習はセーブ地点へ。記録の理由は `PLACE`）。
- 失敗の表示はほかの失敗と同じく出さず、音だけ鳴らす。
- 設置用ブロック以外のコースアイテム（設置できるもの）にも同じ制限がかかる。

## 表示

- 各マスの中央に、1/4の大きさの黄緑の羊毛（BlockDisplay、明るさ最大）を置く。
- 見えるのは、そのコースを遊んでいるプレイヤーと、そのコースの杖かマーカーを持っている運営だけ。
- 必要な人がいないコースの表示は消す。ワールドには保存しない（`gauntlet_placeable` タグ。起動時・チャンク読み込み時に残っていれば消す）。
- 将来レーン方式にするときは、レーンごとの座標に置き換える。
