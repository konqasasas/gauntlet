## 後回しにした事項

| 事項 | 決める場面 |
|---|---|
| 11ランクの色・グラデーション・テーマ | ランク設計 |
| コースのつなぎ方（ランク内の順番） | ランク設計 |
| サーバー記録（WR）の表示 | 記録の不正対策を決めるとき |
| 称号の中身と入手方法 | 実績の設計 |
| サーバー名・IP | 未定（`config.yml` に仮の値） |
| 運営のお知らせ差し込み（`/gauntlet announce` 等） | チャットチャンネル |
| コース選択の差し込み（一覧・コースの詳細の中身） | コースIDとリストの差し込みが決まるとき |
