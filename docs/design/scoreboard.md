# スコアボード・アクションバー・到達率

## スコアボード（サイドバー）

よくあるマイクラサーバーと同じ形にする。常に画面に映るので、**プレイ動画を見た人がどのコースかわかる**ことを重視する。

```
   ◆ (サーバー名) ◆

 Player:
  konqasasas
 Rank:
  [ 7 ]
 Playtime:
  12.5h

 ───────────          ← ここから下はコース中だけ
 Course:
  Lava Stairs
 Best: 87.5%          ← 自己最高の到達率。クリア済みなら「Clear ✓ 24.10s」
 Attempts: 241

 mc.catenaonline.net
```

| 行 | 内容 |
|---|---|
| タイトル | サーバー名（未定。`config.yml` に仮の値） |
| Player | プレイヤー名 |
| Rank | ランクバッジ（[player-display.md](player-display.md)） |
| Playtime | 累計プレイ時間。`12.5h` の形式（小数1桁の時間） |
| Course | コース名。英語の名前を1つだけ持ち、翻訳しない |
| Best | 自己最高の到達率（`87.5%`）。クリア済みなら最速クリアタイム（`Clear ✓ 24.10s`）。ルートがなく未クリアなら `—` |
| Attempts | 本番の挑戦回数（練習は数えない）。試行ログの件数から出す |
| 最下行 | サーバーIP（未定。`config.yml` に仮の値） |

- 見出しは英語だけで、`Player:` のようにコロンを付ける。灰色では背景に埋もれて読みにくかったため、見出しは金色、値は白にする。
- ロビーではコースの部分（区切り線からIPの上まで）を出さない。
- 本番か練習かは表示しない。
- コースにランク・ステージ番号は持たせない（コースは順につないでいく前提のため）。
- 出さないもの：日付、サーバー名の行、ランク内の進み具合、クリア数、オンライン人数、制限時間。
- 作者はプレイヤー制作コースを作るときに追加する。
- サーバー記録（WR）は、記録の不正対策を決めてから検討する。
- タイムアタックなど別モードでは、Best欄の中身をモードごとに切り替えられる作りにする。

### 技術面

- 右側の赤い数字は消す（1.20.3以降の「数字なし」表示）。
- スコアボードは1人ずつ別に作る。スコアボードチームはバニラの名前を隠す用途だけに使う。
- 行の内部名を `#` で始めるとクライアントが表示しないため、`line0` などにする。
- 最大15行。上の案は14行。
- 全員に常に表示する（非表示の設定は設けない）。
- 更新：0.5秒ごと（変わった行だけ書き換える）。

## アクションバー（リアルタイム）

- 毎tick更新する。部品は薄灰色の `|` で区切る。時計アイコンは付けず、時間は日本語でも `12.35s`。
- 本番：`12.35s / 30s | 63.4% | [Q] リトライ`。計測前は `動くと計測開始 | [Q] リトライ`、ゴール後は `クリア 24.10s | 100.0% | [Q] リトライ`。
- 練習：`練習 | 区間 4.20s | 63.4% | [Q] セーブ地点へ | [F] セーブ`。飛行中かどうかや、飛んだ区間が無効になることはアクションバーに出さない（区間タイムのチャットで無効と出す）。→ [hotbar-and-settings.md](hotbar-and-settings.md)
- タイトル表示は使わない。失敗しても理由などは表示せず、音だけ鳴らして戻る。
- セーブの結果はチャットに出す（アクションバーは毎tick上書きされるため）。飛行・プレイヤー表示の切り替えは通知しない。

## 到達率（ルート線）

ランクアップは制限時間内にゴールできるかが勝負なので、タイムより「どこまで行けたか」を出す（ADOFAIの%表示のイメージ）。

### 測り方

- 編集画面の「ルート（到達率）」で、通るべき道を点を結んだ線で登録する（左クリック：今の位置を追加、右クリック：最後の点を削除、Shift＋右クリック：全削除）。杖を持つと赤紫の線で表示する。
- プレイヤーの位置をルート線上のいちばん近い場所に当てはめ、`スタートからの線上の距離 ÷ 全長` で%を出す。
- 壁越しに先の区間へ当てはまって%が飛ばないよう、今の位置に近い区間（前後12ブロック）だけで判定する。
- 本番はその挑戦で一番進んだ位置、練習は今の位置の%を出す。小数1桁（切り捨て）で、ゴールまでは最大99.9%、ゴールで100.0%。
- 近道を許すコースでは、ルートを近道に合わせて引く。

### 保存

- その挑戦での最高値を試行ログの `progress`（0〜1）に保存する。ゴールしたら100%。
- ルート線の変更はコースの版番号 `rev` を上げる。→ [i18n-and-player-data.md](i18n-and-player-data.md)

## 取りやめたもの（2026-10-17）

- **ランク・ステージ番号**（`Rank 1 ‐ Stage 3`）：コースを順につないでいく方式にするため、コースには持たせない。
- **失敗時の表示**（理由・%のタイトル）：失敗しても音だけ鳴らして戻る。
