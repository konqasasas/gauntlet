# スコアボード・アクションバー・到達率

## スコアボード（サイドバー）

よくあるマイクラサーバーと同じ形にする。常に画面に映るので、**プレイ動画を見た人がどのコースかわかる**ことを重視する。

```
   ◆ (サーバー名) ◆

 Player
  konqasasas
 Rank
  [ 7 ]
 Playtime
  12.5h

 ───────────          ← ここから下はコース中だけ
 Rank 1 ‐ Stage 3     ← ボスは「Rank 1 ‐ BOSS」
  Lava Stairs
 Best  87%            ← クリア済みなら「Clear ✓ 24.10s」
 Attempts  24

 play.example.net
```

| 行 | 内容 |
|---|---|
| タイトル | サーバー名（未定。`config.yml` に仮の値） |
| Player | プレイヤー名 |
| Rank | ランクバッジ（[player-display.md](player-display.md)） |
| Playtime | 累計プレイ時間。`12.5h` の形式（小数1桁の時間） |
| コース見出し | `Rank 1 ‐ Stage 3`。番号の持たせ方はランク設計で決める。それまではコースに手入力の欄を設ける想定 |
| コース名 | 英語の名前を1つだけ持ち、翻訳しない（今のコースの「名前」をそのまま使う） |
| Best | 自己最高の到達率。クリア済みなら `Clear ✓` と最速クリアタイム。ルート線のないコースは `Best —` |
| Attempts | 本番の挑戦回数（練習は数えない）。試行ログの件数から出す |
| 最下行 | サーバーIP（未定。`config.yml` に仮の値） |

- ロビーではコースの部分（区切り線からIPの上まで）を出さない。
- 本番か練習かは表示しない。
- 見出し（Player、Rank など）は**英語だけ**。言語ファイルに入れない。
- 出さないもの：日付、サーバー名の行、ランク内の進み具合（4/11）、クリア数、オンライン人数、制限時間。
- 作者はプレイヤー制作コースを作るときに追加する。
- サーバー記録（WR）は、記録の不正対策を決めてから検討する（出す場合は Best の上に `WR 9.80s (Alice)`）。
- タイムアタックなど別モードでは、Best欄を `Best 12.35s` に切り替える。モードごとに出す内容を切り替えられる作りにする。

### 技術面

- 右側の赤い数字は消す（1.20.3以降の「数字なし」表示）。
- スコアボードは1人ずつ別に作る。スコアボードチームは使わない。
- 最大15行。上の案は13行。
- 全員に常に表示する（非表示の設定は設けない）。
- 更新：Best・Attempts は挑戦が終わるたび、Playtime は1分ごと。

## アクションバー（リアルタイム）

- 毎tick更新する。本番は `12.35s  ·  63%` のようにタイマーと今の到達率を並べる。
- 計測を始める前は「動くと計測開始」と `[Q] リトライ`。
- 練習中は区間タイムと到達率、`[Q] セーブ地点へ  [F] セーブ`。→ [hotbar-and-settings.md](hotbar-and-settings.md)
- 到達率の表示は常に出す（非表示の設定は設けない）。
- 失敗したときはタイトルに `63%  (Best 87%)` を出す（個人設定 `fail.title` で消せる）。

## 到達率（ルート線）

ランクアップは制限時間内にゴールできるかが勝負なので、タイムより「どこまで行けたか」を出す（ADOFAIの%表示のイメージ）。

### 測り方

- 編集画面に「ルートの点を追加／最後の点を削除」を足し、通るべき道を点を結んだ線で登録する。杖を持つと線のパーティクルで表示する。
- プレイヤーの位置をルート線上のいちばん近い場所に当てはめ、`スタートからの線上の距離 ÷ 全長` で%を出す。
- 壁越しに先の区間へ当てはまって%が飛ばないよう、今の位置に近い区間だけで判定する。
- 近道を許すコースでは、ルートを近道に合わせて引く。
- 直線距離（縦移動・折り返しに対応できない）や区間数（細かく増えない）は採用しない。

### 保存

- その挑戦での最高値を試行ログの `progress`（0〜1）に保存する。ゴールしたら100%。
- ルート線の変更はコースの版番号 `rev` を上げる。→ [i18n-and-player-data.md](i18n-and-player-data.md)
