# プレイヤー同士の干渉・透明化

## プレイヤー同士の当たり判定はすべてなし

| 種類 | 内容 | 方法 |
|---|---|---|
| 押し合い | ぶつかっても押されない | 1人ずつのスコアボードにある全員入りのチームで衝突ルールを NEVER |
| ブロック設置 | ほかのプレイヤーが立っている場所にも置ける | `BlockCanBuildEvent` で、邪魔なのがほかのプレイヤーだけなら設置可にする。自分の体の中、mob・乗り物がいる場所、支えのない置き方は今までどおり不可 |
| 攻撃 | 殴っても効かない | `EntityDamageByEntityEvent` を取り消す |
| ノックバック | 攻撃・メイスの叩きつけ・ウィンドチャージや爆発で吹き飛ばない | `EntityPushedByEntityAttackEvent` を取り消す |
| 飛び道具 | 矢・トライデント・ウィンドチャージ・エンダーパールなどがすり抜ける | `ProjectileHitEvent` を取り消す（取り消すと飛び続ける） |
| ポーション・釣り竿 | スプラッシュ・残留ポーション、釣り竿の引っかけが効かない | 効果の対象から外す・取り消す |

- 「ほかのプレイヤーによるもの」の判定：プレイヤー本人、飛び道具を撃った人、TNT・残留ポーションの発生元。本人が自分に当てるもの（自分のウィンドチャージで飛ぶなど）は今までどおり。
- mobとプレイヤーの間は今までどおり（コースの仕掛けにmobを使うため）。
- ブロック設置は、クライアント側では一瞬「置けない」と判断されることがあり、少し遅れて出る場合がある。

## 透明化

- チームの「味方の透明を見られる」をオフにし、透明化したプレイヤーをほかの人から完全に見えなくする（同じチームだと半透明に見えるため）。
- 防具・持ち物は、透明化している人について、ほかの全員に毎tickの終わりに「装備なし」を送る（`sendEquipmentChange`）。サーバーが本当の装備を送ったのと同じtickのうちに上書きするので、持ち替えても一瞬も見えない想定。効果が切れたら本当の装備を送り直す。
- プレイヤー自体は非表示にしないので、TABには残る。ProtocolLib などのパケット系プラグインは使わない（Paper標準APIで足りるため）。
- 頭上の名前（TextDisplay）は透明化中は消す。
- 残るもの：ポーション効果のパーティクル（コースで透明化を与えるならパーティクルなしで与える）、足音・設置音。
