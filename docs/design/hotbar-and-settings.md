# ホットバー・個人設定

画面（設定GUI・メニュー）はDialogでカスタムGUIを作る別プロジェクトで扱う。ここでは「何を置くか・何を設定できるか」だけを決める。

## 個人設定

| 項目 | キー | 値 | 初期値 |
|---|---|---|---|
| UI言語 | `ui_lang` | auto / ja / en | auto（クライアントの言語） |
| 翻訳先 | `translate_lang` | UI言語に合わせる / 対応14言語 | UI言語に合わせる |
| 自動翻訳 | `translate_auto` | on / off | off |
| 失敗時のタイトル（`63% (Best 87%)`） | `fail.title` | on / off | on |
| システム音の音量（CP・クリア・失敗などの合図） | `sound.system` | 0〜100%（10%刻み） | 100% |
| コースの演出音の音量（トリガーのサウンド） | `sound.course` | 0〜100%（10%刻み） | 100% |
| プレイヤー表示 | `players.visible` | 表示 / 非表示 | 表示 |

- プレイヤー表示は設定画面ではなく、ホットバー8番のアイテムで切り替える（次回ログインでも覚えておく）。コース中はゴーストの表示切り替えとして働く想定。
- 音量はプラグインが鳴らす音の音量（0〜1）に掛ける。音のカテゴリーは「プレイヤー」なので、クライアント側の「プレイヤー」の音量も重ねて効く。
- 設けないもの：スコアボードの表示（常に表示）、アクションバーの到達率（常に表示）、AFK検知。
- 後で決めるもの：称号（作るか未定）、チャット関連（チャットチャンネルの設計時）、フレンド関連（フレンド機能の設計時）。

## ホットバー

```
         1   2   3  │ 4    │ 5       6     7    │ 8           9
ロビー   ブロック 空き 空き│ 空き  │ 空き      空き   空き  │ プレイヤー表示   （後で決める）
本番     コースアイテム │ 空き  │ 練習へ    空き   空き  │ プレイヤー表示   （後で決める）
練習     コースアイテム │ 空き  │ 本番へ    飛行   空き  │ 〃           〃
```

- **コースアイテムは1〜3番**（現行の1〜4番から変更）。初期装備・トリガーのアイテム付与の置き場所も1〜3番に合わせる。
- **5番**：本番と練習の切り替え。**6番**：練習中の飛行 on/off（本番では空き）。
- **8番**：プレイヤー表示の切り替え。ロビー・コース中を通して常に置く。
- **9番**：後で決める（設定などを含むメニューの想定）。
- 退出用のアイテムは置かない。別のコースを選ぶと自動で抜ける。
- ゴール後もスロットの中身を変えない（現行のゴール後のリトライ・終了アイテムはなくす）。
- 参加者モードと同様、アイテムは動かす・捨てる・持ち替えることができない。名前と説明は見る人の言語で出す。

### キー操作

| キー | 本番 | 練習 |
|---|---|---|
| 1番を持ってQ | スタートへ戻る（計測中ならリタイア） | セーブ地点へ戻る |
| F | なし | セーブ（地面の上のみ。空中・飛行中は拒否してアクションバーで知らせる） |

- 「戻る」「セーブ」のアイテムは置かない。
- Fの押し間違いの救済として、1つ前のセーブを残し、「1つ前のセーブに戻す」を用意する（置き場所は9番の設計で決める）。

### 操作の案内

初心者にもQ・Fが分かるよう、次の4つを重ねる。

1. **アイテム名**：持ち替えたときに表示される名前に操作を書く（例：`Blocks  ‐  [Q] Retry`）。
2. **説明文**：インベントリでのツールチップに操作の一覧を書く。
3. **アクションバー**：計測前は「動くと計測開始」の横に `[Q] リトライ`。練習中は `[Q] セーブ地点へ  [F] セーブ`。
4. **最初の数回だけの案内**：初めて本番・練習に入ったときにタイトルやチャットで案内する。表示回数をプレイヤーデータに記録し、数回で出さなくする。

キーは文字で固定せず、keybindコンポーネント（`key.drop`、`key.swapOffhand`）で表示する。キーを変えている人にも実際のキーが表示される。

## ロビーのブロック

- ロビーでは1番にブロックを持たせ、どこにでも置ける。2〜7番は空き（8・9番は共通）。
- 置いたブロックは一定時間（初期値10秒、`config.yml`）で自動的に消える。ログアウト時にも消す。
- 既存の足場の仕組み（持ち主ごとの記録と片付け）を使う。
- 設置距離・プレイヤーとの重なりなどは通常のMinecraftの制約に従う。
