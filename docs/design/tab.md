# TAB表示

## 役割

- **TAB**：サーバー全体と「誰がいるか」を見る場所。
- **スコアボード**：「自分の今の状況」を見る場所。→ [scoreboard.md](scoreboard.md)

## 構成

```
        ◆ (サーバー名) ◆           ← ヘッダー：ロゴ（グラデーション）
 ─────────────────────────
 [11] [ADMIN] konqasasas   ▮▮▮▮
 [ 7 ] Alice              ▮▮▮▮
 [ 1 ] Bob                ▮▮▮
 ─────────────────────────
     Ping 34ms                     ← フッター：自分のPing
   Tips ブロックは空中でも置ける！  ← ヒント・お知らせ（本文は見る人の言語）
```

### プレイヤー一覧

- 表示は [player-display.md](player-display.md) のとおり `[ 1 ] [ADMIN] 名前`（ランク色）。
- 並び順：ADMIN → ランクの高い順 → 名前。Paperの `setPlayerListOrder` で指定し、スコアボードチームは使わない。
- 名前の右に数字の列は出さない。右端の電波アイコン（Ping）はバニラのまま。

### ヘッダー

- ロゴ（サーバー名。未定なので仮）のみ。オンライン人数は出さない。
- プレイヤーごとに作り、見る人の言語で出す。

### フッター

- **自分のPing**：数値に色を付ける（例：100ms未満は緑、200ms未満は黄、それ以上は赤）。しきい値は `config.yml`。
- **ヒント・お知らせ**：言語ファイルの `tab.hints` にリストで書き、20秒ごとに順に切り替える。頭の見出しは言語によらず `Tips`。

## 更新

- Pingは2秒ごと、ヒントは20秒ごと。
- 名前は表示部品（ランク・役職・称号）が変わったときに更新する。

## 注意点・後回し

- 将来ゴーストを偽のプレイヤーとして出す場合、TABに載せない。
- TABに並べられるのは最大80人。αの規模では問題ないが、将来の課題。
- 運営が今のお知らせを差し込むコマンドは、チャットの全体アナウンスと一緒に設計する。
