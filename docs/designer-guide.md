# デザイナー向けの使い方

ブラウザーで `http://127.0.0.1:4320/` を開いて使います（起動は `node server.mjs`）。操作の作法は Figma に寄せています。

この説明書は、機能が増えるたびに書き足します（計画は [designer-roadmap.md](designer-roadmap.md)）。

## 画面の見方

- 左: 画面の一覧、要素の追加、レイヤー（重なり順。上ほど前面）、素材
- 真ん中: 編集中の画面。上の「編集 / プレビュー / 検証」で表示を切り替える
  - プレビュー: ゲーム画面の概算。クリックで画面の移動を試せる
  - 検証: 書き出した結果を Minecraft の規則で組み立て直した画像（実機に近い）
- 右: 選んでいるものの設定。何も選ばないと、画面とプロジェクトの設定（テーマの色・文字スタイル）

## 選ぶ

| 操作 | 結果 |
|---|---|
| クリック | 要素（グループの中なら、グループ全体）を選ぶ |
| Shift+クリック | 選択に足す・外す |
| 何もない所からドラッグ | 範囲で選ぶ（触れたものをすべて）。Shift で足す |
| Ctrl+A | 今の階層のものをすべて選ぶ |
| ダブルクリック / Enter | グループの中に入る（中の要素を個別に選べる） |
| Esc | 選択を外す。もう一度押すとグループの外へ出る |

- ロックした要素・グループは、画面上でクリックしても選ばれません。レイヤーの一覧からは選べます。背景のような大きな四角形はロックしておくと、上で範囲選択しやすくなります。
- 範囲選択は、画面の外側の余白から始めることもできます。

## 動かす・大きさを変える

| 操作 | 結果 |
|---|---|
| ドラッグ | 選んでいるものをまとめて動かす |
| Alt+ドラッグ | 複製して、複製を動かす |
| 角・辺をドラッグ | 大きさを変える（複数なら、まとめて同じ比率で） |
| 矢印キー | 1px 動かす（Shift で 9px） |
| Shift+ドラッグ | 9px 刻みで動かす |

- 「スナップ」がオンのとき、ほかの要素の端・中心や画面の端・中心に吸い付き、ピンクの線が出ます。
- クリック領域・ボタン・ゲーム内フォントの文字は、上下が 9px の行に合うように動きます（Minecraft の仕様。クリックは 9px 行単位でしか判定できません）。
- 右の欄の X / Y / W / H でも、選んだもの全体の位置・大きさを変えられます。

## 揃える

右の欄の上にあるボタンで、左・左右中央・右・上・上下中央・下に揃えます。

- 2つ以上選んでいるとき: 選んだもの全体の範囲に揃える
- 1つだけのとき: 画面（グループの中に入っているときは、そのグループ）に揃える
- 「⋯横」「⋮縦」: 3つ以上を、等しい間隔に並べる

グループは1つのまとまりとして揃えます。

## グループ

| 操作 | 結果 |
|---|---|
| Ctrl+G | 選んだものをグループにする |
| Ctrl+Shift+G | グループを解除する |

- レイヤーの一覧では、グループは中身を字下げして表示します。▸ / ▾ で開閉。
- 一覧で行をドラッグすると、重なり順を変えたり、グループに出し入れしたりできます（グループの行の真ん中に落とすと中へ入る）。
- 行の名前をダブルクリックすると、名前を変えられます。
- 👁 で表示・非表示、· / 🔒 でロック。グループを非表示にすると、中の要素は書き出しにも出ません。

## 重なり順

| 操作 | 結果 |
|---|---|
| Ctrl+] / Ctrl+[ | 1つ前面へ / 背面へ |
| Ctrl+Shift+] / Ctrl+Shift+[ | 一番前面へ / 一番背面へ |

## コピー・貼り付け・複製

| 操作 | 結果 |
|---|---|
| Ctrl+C / Ctrl+X / Ctrl+V | コピー・切り取り・貼り付け |
| Ctrl+D | 複製（9px ずらす） |
| Delete | 削除 |

- 別の画面にも、ブラウザーの別のタブにも貼り付けられます。別の画面へは同じ位置に、同じ画面へは 9px ずらして貼ります。
- グループごとコピーすると、グループも一緒に貼られます。使っているテーマの色・文字スタイルも、貼り付け先にないときは一緒に追加されます。

## 文字スタイル

「見出し」「本文」「ボタンの文字」のような文字の見た目を登録して、全画面で使い回せます。

- 作る: 文字を選んで「この文字からスタイルを作る」。または、何も選ばない状態の右の欄の「文字スタイル」で「＋ 文字スタイルを追加」。
- 使う: 文字（ボタンのラベルも）の「文字スタイル」で選ぶ。複数選んでまとめて付けることもできる。
- 直す: 何も選ばない状態の右の欄の「文字スタイル」で値を変えると、そのスタイルを使う文字すべてが変わる。
- 1つだけ違う見た目にしたいとき: その文字で「スタイルから切り離す」。今の見た目のまま、スタイルとのつながりが外れる。
- スタイルを削除すると、使っていた文字は今の見た目のまま残る。

## 画像と9分割

- **画像を入れる**: PNG などをキャンバスへドロップするか、左下の「素材」の＋。素材をダブルクリックすると画面に置ける。
- **素材の画面**: 左下の素材を1回クリックすると、右の欄に素材の設定が開く。
  - 名前の変更、使っている場所の一覧（クリックでその要素へ）、未使用なら削除。
  - **差し替え**: 別の画像ファイルを選ぶと、使っている要素がすべて新しい画像になる（分割位置も引き継ぐ）。
  - **1画素の大きさ**: 画像の1画素を何 GUI px で描くか。既定は「実寸」（テクスチャ倍率2なら 0.5 GUI px）。ドット絵を大きく見せたいときは 1 や 2 にする。
- **9分割**: 角丸や飾り枠のボタン・パネルを、画像1枚から好きな大きさで作る方法。四隅は伸ばさず、上下の辺は横だけ、左右の辺は縦だけ、真ん中は両方向に伸ばす。
  1. 素材の画面の「9分割の位置」で、ピンクの線をドラッグして四隅の大きさを決める（数値でも入力できる）。下の「伸ばしたときの見え方」で確かめる。
  2. 画像（またはボタン）の「配置」を「9分割」にする。
  3. 「辺と真ん中」で「伸ばす」か「並べる」（模様を繰り返したいとき）を選ぶ。
  - 1つの要素だけ分割位置を変えたいときは、その要素の「分割位置」にチェックを入れて数値を入れる。
  - 要素が四隅より小さいときは、四隅を同じ比率で縮める。

## 状態（プレイヤーごとに変わる見た目）

設定の ON/OFF、選択中のタブ、音量の目盛りのように、プレイヤーの値によって変わる見た目を作ります。Minecraft の Dialog はマウスを乗せても見た目を変えられないので、変わる見た目はすべて「状態」で作ります。

- **条件を付ける**: 四角形・文字・画像（またはグループ）の右の欄の「状態」で、名前・＝/≠・値を選ぶ。例: `ui_lang＝auto` はその値のときだけ表示、`ui_lang≠auto` はそれ以外のときだけ表示。
  - グループに付けると、中の要素すべてに効く。中の要素にも条件があれば、両方を満たすときだけ表示。
  - ボタン・クリック領域には付けられない（クリック範囲は状態で変えられない）。見た目を変えたいときは、見た目を四角形・文字・画像で作って状態を付け、クリック領域は共通にする。
- **値を切り替えて見る**: キャンバスの上の「状態:」の欄で値を選ぶと、その値のときの見た目になる（編集・プレビュー・検証のすべて）。データは変わらない。「（ほかの値）」は ≠ の見た目を確かめる用。「既定に戻す」で元に戻る。
  - 今の値で見えていない要素は、画面上では選べず、レイヤーの一覧では薄く表示される（一覧からは選べる）。
- **別の状態の見た目を作る**: 見た目を選んで「別の状態の見た目を作る」。複製を同じ位置に作り、複製に別の条件を付ける。例: 「選択中」の青いボタンから「選択していない」灰色のボタンを作り、色を変える。クリック領域は複製されない（共通のまま）。
- **状態の名前と既定値**: 何も選ばない状態の右の欄の「状態（プレイヤーごとの見た目）」で、名前の変更と既定値の設定をする。既定値は、データパックの画面と書き出しの検証に使う値。新しい状態の名前を使うと、既定値は自動で入る。
- 状態の値は、プラグイン側（Gauntlet）の個人設定と同じ表記にする（例: `ui_lang` は `auto` / `ja` / `en`、ON/OFF は `on` / `off`）。

## 元に戻す

Ctrl+Z / Ctrl+Y（または Ctrl+Shift+Z）。まとめて動かした・揃えた操作は、1回で戻ります。
