# 身内向けの直接接続

## このPCで準備した設定

- Paper 26.3、TCPポート `25575`。
- `server-ip=`：LAN経由の接続を受け付けるため、localhost限定を解除。
- `online-mode=true`：正規のMinecraftアカウント認証を維持。
- `white-list=true`、`enforce-whitelist=true`：許可したアカウントのみ参加。
- RCON、Query、管理用サーバー機能は有効化していません。
- 現在許可しているユーザーは `sasas_` のみ。身内のユーザー名は後から追加。

設定の意味は [Paper公式資料](https://docs.papermc.io/paper/reference/server-properties/) を参照してください。

## ルーター

確認したルーターはBuffalo WSR-3600BE4P、設定画面は <http://192.168.11.1/> です。
ルーターの認証情報はチャットに書かず、設定画面にご本人が入力してください。

詳細設定 → セキュリティー → ポート変換に、次の1件を設定します。

| 項目 | 値 |
|---|---|
| グループ名 | Minecraft-Gauntlet（任意） |
| Internet側IPアドレス | エアステーションのInternet側IPアドレス（通常の設定） |
| プロトコル | TCP |
| Internet側ポート | 12799（指定された利用可能ポート） |
| LAN側IPアドレス | 192.168.11.2（このPCの現在のIPv4） |
| LAN側ポート | 25575 |

PCのLANアドレスが変わると転送先が外れます。このPCはDHCPを使用しているため、ルーター側で以下の予約を設定します。

詳細設定 → LAN → DHCPリースで、MACアドレス `D8:43:AE:1D:DC:FC`、IP `192.168.11.2` の端末を探し、「手動割当に変更」を選びます。これはサーバーPCの有線LAN（Realtek Gaming 2.5GbE）のアドレスです。該当端末がなければリース情報の追加から、このMACとIPの組み合わせを登録します。Windows側はDHCPのまま使えます。

手順は [Buffalo公式のDHCP固定割り当て](https://www.buffalo.jp/support/faq/detail/15917.html) を参照してください。この予約はご本人から設定完了の報告を受けています。
ルーターの設定手順と接続方式別の制限は [Buffalo公式手順](https://www.buffalo.jp/support/faq/detail/15022.html) を参照してください。
回線により「利用可能なポート番号」が表示される場合、25575を使えないことがあります。その場合は利用可能な外側TCPポートを選んで内部25575へ転送し、参加者には外側ポートを伝えます。
transix等、IPv4のポート変換自体ができない接続方式もあるため、画面にその接続方式が出ている場合は設定を変更する前に確認します。
DMZやルーターのリモート管理を有効にする必要はありません。

ルーターへの設定はまだ行っていません。WAN側アドレス・接続方式・外部到達性も未確認です。

## 身内の追加と接続

ゲーム内のOPから次を実行します。

```text
/whitelist add 身内のJava版ユーザー名
/whitelist list
```

今回の制作アイテムを使ってもらう相手には、別途 `/op ユーザー名` が必要です。入場許可とOPは別です。

| 接続する人 | 接続先 |
|---|---|
| このPCの自分 | 127.0.0.1:25575 |
| 同じLANの人 | 192.168.11.2:25575 |
| 外の身内 | ルーターのグローバルIPv4:12799 |

グローバルIPv4はルーターのステータスで確認します。WAN側アドレスがプライベートアドレスの場合は、上位ルーターや回線側の共有NATの確認が必要です。
外部到達性は身内の回線、またはスマートフォンのテザリング等、家庭内LAN以外の回線から確認してください。
同じLANからグローバルIPv4へ接続できるかどうかだけでは、外から接続できることを判定できません。
公開中はPCとサーバーの起動が必要です。

## 公開をやめる

ルーターに追加したポート変換1件を削除し、必要なら専用ファイアウォールルールも削除します。
localhost限定に戻す場合はサーバー停止中に `server-ip=127.0.0.1` に変更して再起動します。
