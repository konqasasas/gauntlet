# 自作アイコンの候補

あとで画像アイコンとして自作する候補。

**2026-10-18 更新**: ✕ ◀ ▶ ▼ ✔ ♥ ♡ 🔔 ⚙ 🔒 は、ゲーム内フォントの記号だと9px行の中で位置が偏って枠の中央に揃わないため、`examples/ui_kit.mjs` の `ICONS`（1px の矩形で描くドット絵）に置き換えた。これも仮のもので、デザイナーの画像に差し替える想定。表の「今は…」は置き換え前の記述を含む。

| 記号（現在の仮表示） | 使っている場所 | 用途 | 備考 |
|---|---|---|---|
| ◀ ▶ | コース選択のページ送り | 前・次のページ | 押せないとき（1ページ目の◀など）の薄い版も必要 |
| ★ ☆ | コース選択のフィルター（★1〜2 など）、カードのツールチップ | 難易度 | ツールチップ内でも使えるか要確認（独自フォントのグリフをツールチップに入れる） |
| ▼ | 設定の選択欄（翻訳先） | 選択画面を開く印 | ゲーム内フォントの ▼ は字形が独特 |
| 項目アイコン | 設定の各項目の左（参考画像の♪や🔔のような） | 項目の目印 | 未配置。言語・翻訳・タイトル・音量などの小さなアイコン |
| 🔔 | トップメニュー・お知らせの右上 | お知らせを開く | ゲーム内フォントの 🔔 は字形がほぼ判別できない。未読の赤い印（今は5×5の矩形）もセットで |
| メニューのアイコン | トップメニューのカード（コース選択・ランキング・プロフィール・エモート） | 各カードのアイコン欄 | 今は仮の記号1文字（▦ ♛ ☺ ♪） |
| ランクアップの絵 | トップメニューのランクアップのカード上部（216×79） | 本編の入口の看板 | 今は青い面＋▲。ボスステージの絵などに差し替える想定 |
| エモートのアイコン | エモート・ダンス・ポーズのカード | 各動作の絵 | 今は仮の記号・絵文字（ゲーム内フォントでは判別しにくい） |
| 🔒 | エモート等の未所持カード | 未所持の印 | 今はゲーム内フォントの 🔒 |
| ✔ | コース選択のクリア済みカード | クリア済みの印 | 今は緑の矩形＋ゲーム内フォントの ✔ |
| ▸ | コース選択の並べ替え・フィルター | 選択中の項目の印 | 背景の強調だけで足りるなら不要 |
| ✕ | コース選択の検索条件の横 | 検索条件を消す | 押せないとき（条件なし）の薄い版も必要 |
| ♥ ♡ | コース選択のカード左上、絞り込みの「お気に入り」 | お気に入り登録済み・未登録 | 今はゲーム内フォントの ♥/♡ と矩形。登録済みは塗り、未登録は線だけの2種類 |
| ✕ | コース選択の右上 | 画面を閉じる | 今は赤い矩形＋ゲーム内フォントの ✕（12×11） |

## 作るときの前提

- 本文の画像として焼き込む（タイル化される）か、専用フォントの1文字として登録する。後者ならツールチップや差し込み文字の中でも使える。
- 大きさは9px行に合わせると扱いやすい（例: 8×8、16×16 のアイコンを9px行・18px行に置く）。
- テクスチャ倍率（現在2倍）に合わせて、画像は表示サイズの2倍で描くと滑らかになる。
- 状態（押せる・押せない・選択中）で見た目を変える場合は、状態の切り替え機能が必要（未実装）。
